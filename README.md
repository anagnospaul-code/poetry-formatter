# Poetry Book Formatter

An installable web app for formatting poetry manuscripts into Amazon KDP-ready print PDFs and EPUBs, plus a matching cover builder.

- **Formatter** (`index.html`) — paste or upload poems, check the layout against KDP's trim/margin/page-count rules, download the interior PDF and a Kindle EPUB.
- **Cover Creator** (`cover.html`) — build a full-wrap paperback, hardcover, or ebook cover sized to KDP's spine-width and bleed rules.

Hosted on GitHub Pages and installable to a phone or computer home screen via "Add to Home Screen" / "Install app" in the browser.
